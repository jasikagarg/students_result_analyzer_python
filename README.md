# Student Marks Analyzer (Python)

## Project Description
This is a beginner-friendly Python project that analyzes student performance.
The program accepts student names and subject-wise marks, calculates total marks and percentage,
determines pass/fail status, and identifies the topper.

This project was built to practice Python fundamentals and logical problem-solving.

## Concepts Used
- Variables
- Lists
- Dictionaries
- Loops
- Conditional Statements
- User Input Handling

## Features
- Accepts multiple students
- Accepts multiple subjects per student
- Calculates total marks and percentage
- Determines pass/fail status
- Identifies the topper
- Displays clean and readable output

## How to Run
1. Install Python (version 3.x)
2. Download or clone this repository
3. Run the program using: python student_marks_analyzer.py
